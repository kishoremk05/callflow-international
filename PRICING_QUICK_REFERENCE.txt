┌─ HOW IT WORKS ───────────────────────────────────────────────┐
│                                                               │
│  BEFORE CALL:                                                 │
│   1. Look up pricing    → $0.0144/min (US Mobile)            │
│   2. Estimate 5 min     → $0.072                              │
│   3. Reserve $0.072     → Balance: $10.00 → $9.93            │
│   4. Call proceeds      → ☎️                                  │
│                                                               │
│  AFTER CALL (3:45 = 4 billed minutes):                        │
│   1. Calculate actual   → 4 × $0.0144 = $0.0576              │
│   2. Settle & refund    → $0.072 - $0.0576 = $0.0144         │
│   3. Final balance      → $9.93 + $0.0144 = $9.97            │
│                                                               │
└───────────────────────────────────────────────────────────────┘
